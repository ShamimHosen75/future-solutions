# Brand assets

Placeholder vector versions of the FS monogram, generated to match the brand
spec (silver metallic F, blue→orange gradient S, on #05060A).

Replace these with the official files, keeping the same names so nothing else
needs to change:

| File | Used for |
| --- | --- |
| `logo-mark.svg` | Favicon source, header mark, hero fallback |
| `logo-mark-transparent.svg` | Marks on gradient / glass backgrounds |
| `logo-full.svg` | Footer, email templates, Open Graph |
| `og-mark.svg` | Social share image source |

Optional extras you can drop in: `logo-mark.png` (1024×1024), `fs-logo.glb`
(3D model used by the hero if present — otherwise the hero extrudes the SVG path).
